# Theme drawings: subjects for NanoBanana

Save each drawing here as the file name shown, then run
`uv run --with pillow python tools/make_vignettes.py` (or ask Claude to).
Use the style prompt in the README (Themes → Theme drawings) and swap in the subject.
Figures fill most of the height; the scene about twice as wide as it is tall.
